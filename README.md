# Waste Material Segregation (CNN)

A **convolutional neural network** that classifies images of waste into distinct categories — cardboard, glass, paper, plastic and more — to support automated recycling and reduce landfill waste.

## Objective

Accurately categorise waste materials from images so segregation can be automated, improving recycling efficiency and promoting sustainable waste management.

## Approach

- Image loading, resizing and normalisation
- Data augmentation to improve generalisation
- A CNN architecture (convolution + pooling + dense layers) for multi-class classification
- Training with validation monitoring and evaluation on a held-out test set (accuracy, confusion matrix)

## Tech

Python, TensorFlow / Keras, NumPy, Matplotlib (Jupyter Notebook)
